# Northern Suite

Installers and updates for **Northern Suite** by Pulse-911 System.

- **Install:** download `NorthernSuite-Setup.exe` from the [latest release](https://github.com/NorthernDev26/northernsuite-releases/releases/latest) and run it.
- **Updates:** installed copies check this page and offer new versions automatically.

Your agency's IT department may need to trust the Pulse-911 System code-signing certificate first.
